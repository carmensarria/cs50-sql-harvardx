# Cyberchase

This exercise is part of Week 0 of CS50's Introduction to Databases with SQL.

## Description

Cyberchase consists of multiple SQL queries contained in a single file, each solving a different task related to data filtering and retrieval.

## Files included

- cyberchase.sql

## SQL Concepts Used

- SELECT statements
- WHERE filtering
- ORDER BY
- LIMIT
- Data retrieval

## Skills Developed

- Writing basic SQL queries
- Extracting information from datasets
- Applying filtering conditions
- Interpreting query results
