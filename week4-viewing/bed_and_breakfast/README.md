# Bed and Breakfast

This exercise is part of Week 4 of CS50's Introduction to Databases with SQL.

## Description

Bed and Breakfast analyzes Airbnb-style data from Boston using SQL views.  
The goal is to extract insights about listings, availability, and reviews using structured queries.

The dataset includes three tables:
- listings
- reviews
- availabilities

## Files Included

- no_descriptions.sql
- one_bedrooms.sql
- available.sql
- frequently_reviewed.sql
- june_vacancies.sql

## SQL Concepts Used

- CREATE VIEW
- SELECT queries
- JOIN operations
- WHERE filtering
- Aggregation (COUNT)
- GROUP BY
- ORDER BY and LIMIT
- String filtering
- Date filtering
- Data analysis using relational tables

## Key Insights Extracted

- Listings without long text descriptions
- Properties with exactly one bedroom
- Availability status of listings
- Most frequently reviewed properties
- Vacancy analysis for June 2023
