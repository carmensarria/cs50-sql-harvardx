# From the Deep

This exercise is part of Week 6 of CS50's Introduction to Databases with SQL.

## Description

From the Deep focuses on the design of distributed database systems and the trade-offs involved in partitioning data across multiple servers.
The exercise uses a fictional submarine, AquaByte Explorer, to explore different strategies for distributing observations across multiple boats. The goal is to compare how different partitioning methods affect data distribution and query performance.

## Partitioning Strategies

The exercise explores three approaches:

- Random partitioning
- Partitioning by hour
- Partitioning by hash value

Each approach has different advantages and disadvantages depending on the type of queries being performed and how evenly the data is distributed.
